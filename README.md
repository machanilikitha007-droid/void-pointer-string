# Void Pointer with String Data

## Author
M.Likitha

## Description
This program demonstrates how a void pointer can be used
to pass a character array (string) to a function.

The void pointer is converted to a character pointer before
the string is displayed.

## Concepts Used
- Void pointer
- Character array
- String
- Functions
- Type casting
- Pointer to character data

## How to Run

gcc void_pointer_string.c -o void_pointer_string

./void_pointer_string

## Sample Output

String: Hello, C Programming!

gcc void_pointer_sizeof.c -o void_pointer_sizeof
./void_pointer_sizeof

Size of int: 4 bytes
Size of float: 4 bytes
Size of char: 1 byte
